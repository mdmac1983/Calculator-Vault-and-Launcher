# Calculator-Vault-and-Launcher

1. **Calculator Disguise** - Scientific calculator with teal function buttons, dark number pad. PIN entry via calculator, unlock with `=`

2. **Launcher Home** - Android launcher with widgets (weather, calendar), app grid, time/date header

3. **Vault Files Tab** - Encrypted file manager with folder grid, bottom navigation with 5 tabs, footer

4. **Vault Passwords Tab** - Password entries with category icons (Website, Banking, Credit Card, Contacts)

5. **Vault Settings Tab** - Launcher customization options (theme, PIN, lock home screen, icon pack, wallpaper, app name)

**Features demonstrated:**
- Dark theme with teal accents
- Bottom navigation for 5 vault tabs
- Footer: "2026 @mdmac + @orion FTF"
